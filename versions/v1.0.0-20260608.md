# v1.0.0 (2026-06-08)

初始版本发布

## 核心功能

### 用户系统
- 用户注册、登录
- 邮箱验证
- 忘记密码
- 个人资料管理

### 财税专家对话
- **基础版**：财税政策问答
- **专业版**：方案分析、税费计算、专业建议
- 流式对话打字机效果
- 对话历史记录
- 记忆功能（跨会话记住关键信息）
- RAG 检索增强回答

### 知识库 RAG
- PDF 文件上传和索引
- 智能分 chunk 策略（按政策条目）
- 向量检索 + 关键词兜底
- 引用文档一键保存
- 知识库文件管理

### 订阅与支付
- 基础版/专业版订阅
- 支付宝支付
- 微信支付
- Token 充值系统
- Token 余额、消耗统计
- 退款申请

### 管理后台
- 用户管理（启用/禁用、赠送Token）
- Agent 配置管理
- 订阅等级管理
- 知识库文件管理
- 支付订单管理
- 退款申请审批
- 审计日志
- 系统配置
- 通知管理
- 数据统计（用户、对话、Token）

### 基础设施
- Redis 缓存集成
- API 限流中间件
- Webhook 通知
- 邮件通知服务
- 定时任务（订阅到期检查、政策抓取）
- Docker 部署支持

### 前端特性
- 深色模式
- 中英文切换
- 移动端适配
- 对话满意度评价（👍👎）
- 对话导出

## 技术栈

- **前端**：Vue 3 + Vite + Element Plus + Pinia
- **后端**：FastAPI + SQLAlchemy + PostgreSQL
- **向量库**：Qdrant
- **缓存**：Redis
- **部署**：Docker Compose

## 数据库

- PostgreSQL 数据库
- 16 张数据表（users, agents, subscriptions, token_accounts, knowledge_files 等）
